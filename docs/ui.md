# 本地图形客户端

- 状态：本地工作台开发中。
- 依据：图形入口复用既有客户端能力，视觉沿用VideoSeed的硬塑料表面、短阴影和高对比文字。

## 进程与边界

服务端默认127.0.0.1:5184，客户端图形服务默认127.0.0.1:5183。npm run ui先用esbuild构建browser/依赖入口，再启动本地图形服务。web/包含HTML、CSS及浏览器ES模块，web/vendor/为忽略的本机构建产物，不请求CDN。界面使用本地HTTP桥接访问ApiClient、同步和运行模块，后端规则与CLI共用。

首次启动或会话无效时显示连接与登录页，员工填写服务端、Office地址及用户名密码，不编辑环境文件。地址与登录session由ConnectionStore保存在当前用户私有目录，人和Agent默认共享同一配置的会话，密码不保存。图形工作台忽略兼容旧脚本的环境长期令牌；浏览器只取得显示信息与本机csrfToken，不取得服务端Bearer。图形服务仅回环监听并核对Host、Origin、会话头，页面资源使用同源CSP。连接资料位置、CLI协作与安全边界见[登录说明](login.md)。

CAPSULE_UI_PORT控制本机监听端口。CAPSULE_UI_UPLOAD_BYTES控制单次原件上传上限，默认8GiB，必须为正的安全整数字节数；最终还受服务端上传限额约束。上传先暂存于客户端工作区uploads/，再调用服务端接口，结束时清理本次暂存。声明长度或实际接收字节超限时返回JSON 413，停止读取尚未完成的请求并关闭连接；中断或失败也清理本次暂存。JSON action请求固定最多1MiB，调大上传限额不会扩大正文或操作JSON的限制。其他连接配置见[README](../README.md)。

## 界面接口

知识库cube菜单的“连接与登录”按需打开账户切换、修改密码及退出入口；“账户与管理”打开当前身份、员工登录名/显示名称/重设密码、兼容长期凭据、当前cap三档权限、审计和备份弹窗，不增加常驻栏。管理员操作复用CLI的src/operations/admin.mjs。兼容长期凭据仅在签发时展示，关闭或切页清除DOM，不进入/ui/session、localStorage或登录配置；普通Agent直接使用相同账户密码经CLI登录，不额外签发令牌。详见[员工身份](../../capsule-server/docs/access.md)与[备份恢复](../../capsule-server/docs/backups.md)。

账户只分管理员admin和普通员工editor。管理员为每个cap统一设置所有非管理员的edit（读写）、read（只读）或none（不可访问），新建与复制的cap默认edit；不设置逐员工例外。三档表单通过cap-access复用CLI接口，修改携权限revision，不使用正文token，不受内容回撤影响。管理员始终拥有全部权限。

切换连接、其他账户、退出或改密前先处理未保存正文、表格、属性及Office修改；有草稿时界面拒绝切换。同一服务器、同一用户重新登录可保留草稿，另以稳定ID核对，防止用户名被复用。外部CLI切换同一配置后，旧页面隐藏原内容并提示重新登录原账户处理草稿，不将其带给新账户；普通网络错误不视为换人。身份变更还会停止本机管理的Skill并重建会话。具体规则见登录说明。

当前身份来自me，cap响应permissions控制编辑、上传、回撤及属性保存；身份无效时收起写入口。只读cap的正文、属性与Office只查询活动，不登记编辑心跳，Office配置为view。前端控制用于呈现，服务端在读取/执行前最终核对；客户端持有的旧权限不能绕过撤销。清除和全局组织只向管理员提供。

- GET /ui/session返回csrfToken、稳定连接标识connectionKey、serverUrl与officeEditorUrl。
- POST /ui/action接收action及对应字段，返回既有客户端操作结果。实体修改携读取时的cap token，位置修改携对应子树token；组织事务使用预演基线，Office保存使用已绑定基线的会话。创建、挂载、活动登记和Skill本机生命周期有各自参数，不统一要求实体token；具体以action声明和[服务端API契约](../../capsule-server/docs/api.md)为准。事件和错误回执继续保留。
- GET /ui/content?name=...&entry=...提供原件预览，支持Range；小原件可复用本机有界缓存。响应含ETag时使用Cache-Control: private, no-cache，无ETag时使用no-store。可选version绑定正文的cap token，错版返回409；download=1下载当前原件，工作台生成的下载链接不携旧正文version。具体重验与流量规则见[原件缓存](content-cache.md)。
- PUT /ui/upload?name=...&entry=...接收原件字节，携If-Match与X-Capsule-Session；临时保存后通过统一客户端上传，失败清理暂存。

read/details action采用2分钟读取期限，并随浏览器断连取消上游只读请求；普通JSON查询默认30秒，媒体下载使用独立期限。超时后按查询重试，写入结果继续按原回执核对。

action能力及参数由src/ui/actions.mjs维护，覆盖cap读写、发现、位置组织、版本事件、Office、表格、同步、运行与Skill本机注册。位置的move、where、search、organize-inspect/organize/organize-receipt及edit复用CLI的src/operations/，不另建界面业务规则。Office会话与表格读写复用客户端适配。GET /ui/office/recovery?id=...下载已保留的冲突原件。revert和delete返回入队事件由界面轮询，run仅在用户明确操作后执行。

创建cap和新增挂载是两个明确请求。挂载失败时应说明cap已创建并能从全部cap找回，避免重试创建造成重复或名称冲突。

知识节点菜单与当前文件菜单均提供“复制为新cap”。普通员工只需有源cap读取权限即可复制；对话框明确副本独立保存、默认向普通员工开放读写，不继承源权限或版本历史。副本只包含已保存版本，不包括本地草稿，源无需编辑占用。默认挂载至源所在虚拟目录，可留空仅创建。复制统一调用src/operations/copy.mjs，目标全库唯一，单文件保留扩展名。复制结果未知或发布中时保留事件ID并禁用重复提交；副本已创建但挂载失败时切到全部cap找回，不重复复制。

## 状态与草稿

选择cap和读取文件按请求序号绑定，晚到响应不覆盖其他选择。正文草稿保存读取时的baseToken，后台刷新不替换旧草稿的基线。保存失败保留正文和基线；版本冲突需重读、核对或合并，暂时占用和待处理事件则先查询实际状态，不把所有409都当成版本冲突。

导航保护覆盖离开Office前后的异步步骤：新选择会使旧请求失效，第二列文件、历史和重新打开也核对当前上下文。离开被拒绝时保留原编辑器。多个本机会话失效通知共用一次重连；读取尚未完成时恢复原选择，同账户会话更新后刷新媒体与下载链接，不重放写入、不重建脏正文、表格或Office实例。

简介草稿同样绑定读取时的token，外部更新不能替换未提交简介的基线。切换内容不隐式保存，离开页面时检查未保存草稿。

### 并发活动提示

实际修改另由编辑租约保护：正文、属性与数据表默认阅读，点击“占用并编辑”才申请整个cap的独占租约；Office默认view浏览，明确编辑后改用office共享占用。保存、结束编辑、放弃或切换立即释放，失联后20秒到期，5秒续期。失效时保存被冻结，草稿及原token保留，重新获取由用户明确触发。同tab的正文与属性共享占用引用，关闭一个面板不会释放另一个仍在使用的引用。完整协议和异常恢复见[并发说明](../../capsule-server/docs/concurrency.md)。

当前内容标题和属性弹窗标题按需常显胶囊活动：真实编辑租约持有人、其他客户端的编辑会话、有待保存更改、排队或处理中事件及Office状态，点击查看范围与事件ID。服务端提供queue健康字段时，阻塞状态优先显示“事件待恢复”或“队列异常”，详情保留错误码和事件ID；兼容没有该字段的旧服务，不从错误列表为空推断整体健康。编辑会话数不是人数，Office状态包含本客户端；分组和事件列表超限时明确说明，仅显示部分。没有新增常驻栏；presence本身不阻止保存，独立租约由服务端强制校验，实体与位置仍用各自token核对版本。

队列阻塞若只有LOCK_BUSY，按暂时占用显示“等待占用释放”，不标为恢复故障。保存响应也按机器码区分：LOCK_BUSY提示内容正被处理，EVENT_BUSY保留原事件ID并提示先查询，WORKSPACE_BUSY提示服务实例占用；只有VERSION_CONFLICT或已核实token变化提示版本冲突。失败不改变草稿、原token与事件回执。

浏览器每个tab拥有独立clientId，中央工作区和属性弹窗分别维护自己的sessionId；查看其他cap属性不改变中央内容或释放其会话。持有租约的文本、数据表、Office和属性说明表单每10秒更新presence，dirty变化约500ms内更新；独立租约按自己的5秒节奏续期。只读浏览只查询活动，不登记编辑心跳。切换内容、关闭弹窗和pagehide时取消旧请求并释放其独立session，旧响应不能替换新活动状态或释放新会话；BFCache返回时可重新查询presence，编辑租约须明确重新获取。离开的未保存草稿仍保留在本机，但不代表该内容仍被打开编辑。

presence为非排他提示，不修改cap正文、Git历史或持久元数据，也不携实体token。断线、无效回执或查询8秒未返回显示“占用状态未知”，请求有界超时后继续重试，不把查询失败显示成无人编辑；后台失败不产生未处理的Promise拒绝。正常心跳45秒未续期由服务端自动清理。释放成功后，服务端用有界的120秒释放记录拒绝同一session迟到的心跳；释放无法送达的残留由TTL清理。释放记录的容量及跨cap身份限制见服务端契约。Office iframe只更新活动提示，不因该轮询重建。CLI的`capsule activity 名称`经同一只读操作查询实际状态，不自动登记或心跳。

## 内容与侧栏

原件通过本机有界缓存与ETag条件重验复用，Range不预取全片。隐藏标签暂停纯查询，属性未变版本不重取详述；租约续期和保存中的回执确认持续进行。具体流量与缓存规则见[原件缓存与流量](content-cache.md)。

左侧第一列负责虚拟知识结构，知识树在当前位置展开。点击左侧知识库cube图标切换视图和类别或使用工作台菜单；顶部过滤框常驻，⌘K / Ctrl+K展开导航并聚焦输入；query和类别联合过滤服务端结果，清空恢复树的原展开与已读取范围，保留过滤期间的新选择且不自动切换内容。选中目录cap后，其右侧第二列展开原生文件树，数据库还可切换数据表。中央负责当前内容的阅读、编辑或操作；属性改为节点按钮按需打开的独立弹窗，不再占用右侧固定列。亮色与深色主题使用同一布局和类型色，不以模糊或低对比文字表达层级。

第二列先读取当前cap的直接子项，展开目录时才读取其文件，分页按钮留在对应目录下。书稿正文README.md与assets在同一根层，配图数量不会把正文推到后续页。续页核对同一目录版本，切换cap时取消旧列表读取，分页保留展开、当前文件和滚动位置。旧接口明确拒绝directory时回退为平铺分页，Markdown仍提供根正文入口。中央文件概览与CLI继续使用原平铺列表。

已打开页面每30秒只读核对当前列表和可见展开层，保留每层已加载页数；后台标签暂停，恢复可见时立即核对。CLI或其他同事挂载、移动后，目录变化自动显示，不切换中央内容或触及草稿。未变不重绘，变化时保留当前选择、滚动与键盘焦点；暂时读取失败保留旧子层，只在完整父列表确认位置移除时清理其隐藏展开缓存。旧异步响应不能覆盖新过滤、展开或分页。首次更新到此客户端版本时，已有旧页面需刷新一次加载新模块，之后不需要靠刷新页面获知外部目录变更。

工作区不设置全局顶栏、活动栏或状态底栏。知识库cube菜单提供事件与运行面板、Agent、主题和连接与登录；正常连接不常驻提示，异常显示重试或重新登录入口，需关注的失败或冲突显示角标。事件面板按需展开，后台以较低频率查询，回撤队列的监测仍持续执行。

外层面板贴浏览器内容边缘，列间只保留1px分隔，不设置外边距、列间隙、外圆角或卡片阴影。内容标题最左的按钮、知识库菜单或⌘B / Ctrl+B可折叠整个左侧导航；知识树与目录第二列一并收起，展开后保留原选择和树状态。两列边界可拖动、用方向键调宽，Home/End取边界；视口约束保证中央工作区仍有空间，偏好仅存本机。折叠偏好仅存在本机浏览器，快捷键避开输入框、编辑器、对话框和菜单。

内容区只保留一行34px标题。文件名悬停可看完整位置，右侧菜单或右键标题提供上传、历史与回撤、刷新、下载和版本信息。Markdown阅读与编辑切换在悬停或键盘聚焦时出现，也可从菜单进入。已保存状态保持安静；未保存、保存中和冲突明确显示，能提交时显示保存按钮，正文支持⌘S / Ctrl+S。菜单操作绑定打开时的内容上下文，切换内容关闭旧菜单。

正文和Office不重复设置格式栏、保存底栏或常驻使用说明。保存说明与版本详情按需打开；错误、冲突和恢复原件入口仍保留。正文使用显式保存和原token校验，Office保留离开保护，回撤仍经事件队列；SQLite网格使用自身的表格提交控件。

较长正文使用独立分段阅读器：首次取240行，再在约200行附近的段落边界展示，必要时续取以完整保留fenced代码块与HTML表格；只渲染当前段及其配图。上一段、下一段和行号跳转继续读取同一token，跨段目录和任意行由服务端定位安全起点，不逐页下载前文或预载全书图片。翻页释放旧媒体，版本变化不会拼接新旧正文。分页控件悬浮于中央阅读区底部，正文独立滚动；随控件实际高度为正文末尾留空，窄列自动换行。纯阅读时←上一段、→下一段，Page Up/Page Down保留原生滚动；输入框、选择文字、媒体、菜单、对话框和侧栏操作不翻页，加载中或首末边界不发无效请求，翻页读取失败保留当前段与返回记录供重试。切换内容时移除键盘与尺寸监听。短全文继续进入原编辑器；文件菜单“完整载入以编辑”会先读取完整正文并检查JSON提交预算，超限继续只读，可下载原件。编辑器另拒绝非from=1、仍有nextLine或truncated的片段，不会把阅读页覆盖成整本文件。

分段阅读仅缓存当前胶囊同一版本的最近8段，正文预算4MiB（取UTF-8字节与UTF-16估算较大值），展示缓存前独立重验权限和token/commit。相邻段历史最多128条，耗尽后仍可由服务端定位继续向前；“上一段”按正文顺序，不把目录跳转当作无限浏览历史。撤权会清除阅读正文和缓存；网络故障保留当前段供核对，不离线翻阅旧缓存。切换内容释放该阅读器缓存。普通短行文本约200行即分页，不等到数十万行；显式代码块、表格和注释保持完整，并受2MiB、10000行、64次续读上限约束。结构过大时明确提示获取原件，不尝试无限渲染。管道表分隔行按单元格线性检查，HTML表格和锚点扫描限定单个受支持标签。客户端分段扫描屏蔽同一行内成对反引号代码跨度中的伪表格标签及锚点，每行最多4096个反引号段；跨行代码跨度的服务端定位另有[API预算](../../capsule-server/docs/api.md)，这些结构规则不覆盖完整CommonMark语法。

首段慢读不会被同版本后台轮询重启，离开时取消当前读取。完整载入用于编辑时校验每页起止、总行数、nextLine和原token，拒绝缺行、重叠及版本变化；未完成的读取不能作为全文保存。Markdown在解析前限制2MiB正文，在建DOM前另检查30000个结构节点的估算预算，超复杂内容仅显示说明，普通原件仍可下载；该保护不改写正文或版本。嵌入媒体绑定当前正文或草稿的原token，错版附件只显示无法加载提示；检查更新后重新取同版本正文与媒体，不把旧正文与新附件混搭。

Skill也复用同一标题行：注册、协作页面启停、运行CLI、查看SKILL.md和本机路径放在标题菜单，正常状态及注册提交放在按需信息中，不再设置额外工具栏或CLI说明栏。启动/关闭期间、失败、待核对会话和可用升级仍提供可见提示；后台状态刷新保留正在使用的iframe。

## 节点属性

知识库cap行的属性按钮直接打开弹窗，也可从节点菜单进入，不切换中央选择或重建Office编辑器。弹窗固定显示名称、简述、详述；名称只读可复制，简述沿用最多180字符的description。类别与版本信息折叠披露，退出旧的右侧属性栏、类型操作指南及重复简介。

详述通过统一details接口按80行分页读取：text使用原件，Markdown使用README.md，code使用SKILL.md，files/database使用说明.md，后者尚未创建时展示空详述。文字正文只读展示，优先引用中央已有未保存草稿；明确点击“编辑正文”才返回中央编辑，数据库说明也使用统一details保存入口，不走SQL写入。不存在第二份可编辑正文草稿。

详述默认按Markdown渲染，复用正文的markdown-it与DOMPurify，支持标题、列表、表格和代码块。原始HTML仅开放table及表格子标签、br和a[id]锚点子集，进入片段及完整输出时都经过清理；脚本、style、iframe、form、原始外源媒体和事件属性不开放。媒体/Office等元数据详述通过“编辑详述”修改Markdown原文，“阅读”预览同一份未保存草稿；切换视图不保存、不更换版本基线。目录cap的相对附件只在自身范围内读取，单文件cap不派生附件目录，HTTPS链接保留。弹窗内锚点限定当前阅读区，同一版本和读取上下文的轮询不重建正文未变的媒体节点；版本变化可重新创建干净的属性视图，切换编辑或关闭弹窗时释放音视频。

媒体、Office及普通file的长详述只保存在顶层SQLite的details，并随cap版本和回撤管理；stat、知识树及列表不携带全文。弹窗完整读取后允许编辑，简述与长详述同次PUT提交，截断的预览不会作为完整正文覆盖。请求整体仍限1MiB（含JSON编码开销），冲突保留草稿和原token。关闭再打开保留未提交说明，外部变更只自动刷新干净状态。

图片、音频和视频增加按需展开的“浏览”，原件从统一内容接口流式读取，不自动播放。关闭弹窗暂停音视频并释放源，浏览不影响中央Office与编辑草稿。媒体主视图去掉重复类型/文件名栏、下载页脚和音频装饰卡；文件集合直接呈现条目，第二列删去固定说明行。

## 断链与清除

知识树节点悬停或键盘聚焦时显示操作按钮，也可右键节点。断开当前挂载先读取位置子树token，只卸载所选叶位置；有子挂载时需先逐个断开或移动。断链保留cap、全部版本及本地草稿，当前阅读内容继续保留并清除失效的路径提示，可从“全部 cap”访问。

清除整个cap先读取服务端removal预览，展示全部挂载及阻止原因，输入完整名称确认后携实体token与挂载范围mountsToken入队。清除删除cap内容、独立Git历史和全部挂载，不能通过版本回撤恢复；其他cap的子挂载、未完成事件及活跃Office会话阻止清除。Office应先保存并切换到其他内容，等待文档服务关闭回调，再重新预览。

界面在清除事件确认成功、并核实当前没有同名新cap后，才清掉对应cap的选择、正文/表格/属性草稿及编辑器。若名称已被新cap复用，保留当前内容和草稿并提示核对；清除其他cap不影响当前阅读。失败或结果未知保留当前状态和事件ID，后台继续查询已知事件，不自动重复提交。清除不扫描或删除客户端独立缓存、运行目录和日志；这些本机材料由各自生命周期管理。服务端恢复暂存与已接收的Office冲突恢复材料的边界见服务端API契约。

## 内容呈现

- Markdown cap固定README.md与assets/，使用markdown-it解析及DOMPurify清理，支持当前cap内的相对图片、音频和视频嵌入；HTML仅保留前述表格与锚点子集，媒体不跨cap引用。上传默认进入assets/，正文通过编辑保存。完整书稿与配图可由CLI import目录一次导入，不丢弃书稿原有表格与目录锚点。普通text继续平铺；已有text不会自动转换。代码只接受Skill形态，默认呈现SKILL说明与本机注册入口，独立CLI和可选协作页面见[skills.md](skills.md)，原生文件仍可行号编辑。
- 图片使用独立预览画布，音频与视频使用原生媒体控制，不自动播放。
- Office中央主视图嵌入ONLYOFFICE Docs，直接编辑DOCX/XLSX/PPTX。保存等待cap提交确认，后台刷新保持活跃编辑器。模板和单元格小表单退出主交互，额外的Agent提取与批处理命令保留，见[Office说明](office.md)。
- 文件集合显示自身原生条目，SQLite使用Tabulator显示表与分页查询结果，业务单元格可编辑后统一提交。无主键、系统表和自定义查询结果只读。数据库媒体仍通过统一内容接口访问，详见[数据库说明](database.md)。

ONLYOFFICE脚本和连接使用CAPSULE_ONLYOFFICE_URL的固定来源；frame另允许127.0.0.1和localhost回环HTTP端口供本机Skill使用，工作台自身脚本不启用inline/eval。普通Bearer与文档服务JWT密钥不进入浏览器，编辑器配置使用短期票据。编辑器“变化已收集”不作为cap已保存，保存期间继续输入会保留dirty。冲突/失败保持会话，已有恢复原件时提供下载，服务端尚未收到原件时提示通过编辑器自行下载；明确确认关闭时提醒恢复原件不一定含之后新输入。表格草稿保留原token，切表后仍可恢复；保存期间共享草稿锁定，不能通过切表再切回来覆盖待提交数据。

## 开发示例

演示数据通过独立脚本显式种入服务端，界面读取真实cap，不在浏览器伪造业务记录。样例包含文本、图片、音视频、Word、Excel、文件集合、数据库及可运行代码。现有同名cap不会被种入脚本覆盖，来源与重建方法见[开发示例](demo-data.md)。空库仍显示实际空状态和新建入口。

静态检查覆盖浏览器模块。HTTP测试验证静态资源、会话和同源限制、代理凭据、原件流及写入冲突。Playwright使用隔离库验证实际浏览器正文、导航、登录与并发操作，运行入口与Office服务替身边界见[前端测试说明](ui-testing.md)。视觉与交互由用户在打开的工作台验收。
